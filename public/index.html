Paying

Call a paid route with no payment and you get an HTTP 402 whose accepts array lists both rails (USDC on Base, USDC on Solana) plus the route's outputSchema — the exact request shape to send and the response shape you get back. Retry with an X-PAYMENT header and the artifact comes back in the same response.

const fetchWithPay = wrapFetchWithPayment(fetch, account);
const res = await fetchWithPay("http://localhost:4037/track");
